# Akiya Inbound Sales — Simple MVP

## 目的
海外顧客を持つ空き家・不動産・移住支援会社に対し、東北地方の現地パートナーとして営業する。

売るものは最初から広げず、次の4つに限定する。

1. 現地確認・写真/動画撮影
2. 内装・補修視点での状態確認
3. リノベーション/補修業者の現地調整・進捗確認
4. 購入後の定期巡回・管理支援

※ 不動産仲介など許認可が必要な業務は、適切な資格を持つ事業者と連携する。

## 最小営業フロー

候補会社を見つける
→ 公開情報だけ確認する
→ 10点満点で優先順位を付ける
→ 個別営業文を作る
→ 人が確認して送る
→ 返信/次回対応だけ記録する

自動送信、大量送信、有料CRM、複雑なAI API、専用ダッシュボードはPhase 1では作らない。

## 営業先データ（最小10項目）

- company_name: 会社名
- website: 公式サイト
- contact: 公開問い合わせ先/フォーム
- foreign_support: 海外顧客対応 yes/no/unknown
- tohoku_support: 東北対応 yes/no/unknown
- management: 管理サービス yes/no/unknown
- renovation: 改修支援 yes/no/unknown
- score: 0-10
- status: new/draft/sent/replied/meeting/won/lost
- next_action: 次にすること

## スコアリング

- 海外顧客対応あり: +3
- 空き家/地方物件を扱う: +2
- 購入後管理あり: +2
- リノベーション支援あり: +1
- 全国対応または東北対応: +1
- パートナー/業者ネットワークを明記: +1

7点以上: 優先営業
5-6点: 次点
4点以下: 保留

## 営業メッセージの核

件名例: 東北エリアの現地調査・物件管理パートナーについて

伝える内容:
- 東北エリアで現地対応可能
- 内装・補修関連の現場経験 約18年
- 写真撮影だけでなく、床・建具・家具・水回り等を現場視点で確認できる
- 海外顧客が現地に来られない場合の「目と手」になれる
- まず1件の現地確認など、小さな業務から試せる

## Phase 1 運用

目標は「システム完成」ではなく提携先1社を得ること。

1. 20〜30社を候補登録
2. 7点以上を優先
3. まず10社へ個別営業
4. 返信内容を記録
5. 7〜10日後に未返信先を1回フォロー
6. 反応の良い訴求だけ残す

## 費用方針

既存のPython/Flask/SQLite/GitHub基盤を流用する。外部AI API、有料CRM、メール配信SaaSは導入しない。Phase 1の追加固定費は原則0円を目標とする。

## 実装方針

既存の民泊営業MVPを壊さない。Akiya Inboundは独立した小さな営業チャネルとして追加し、既存の営業ログ/ステータス管理の考え方を流用する。

最初に必要なのは以下だけ。

- 候補会社CSV
- スコア計算
- 営業文テンプレート
- 送信/返信/次回対応の記録

実際の営業先情報・個人情報・メールアドレス等はPublic GitHubへコミットしない。

## 成功判定

10社営業した時点で次を確認する。

- 返信数
- 面談数
- 現地対応ニーズの有無
- どのサービスへの関心が高いか

反応が出るまで機能追加を優先しない。
