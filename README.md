# 東北リペア営業ノート（Phase 1）

東北6県の民泊・宿泊施設へ、床・建具・家具・水回りのキズ補修／コーティングを提案するための営業支援Webアプリです。

> **交換・リフォームする前に、補修という選択肢を。**
> 宿泊施設の修繕コストと稼働停止を減らす、東北の現地メンテナンスパートナーを目指します。

## できること

- 施設・運営会社・連絡先・公開情報の出典・営業上の特徴を登録／編集
- 条件に応じた優先度（S / A / B / C）と判定理由の自動生成
- キーワード、県、優先度、営業ステータスによる検索・絞り込み
- 一覧から営業ステータスを更新
- 標準／ペット可／複数施設運営向けの営業文テンプレートを生成しコピー
- Excelでも文字化けしにくいUTF-8（BOM付き）CSV出力
- 初回起動時に架空のサンプルデータ5件を自動投入

営業文は**下書きだけ**を生成します。自動送信や大量送信は行わず、最終確認と送信は必ず人が行う設計です。スクレイピング機能もありません。公開情報を手作業で登録し、各サイトの利用規約と `robots.txt` を守ってください。

## 技術構成

| 項目 | 採用技術 | 理由 |
|---|---|---|
| Web | Python + Flask | 小規模で分かりやすく、保守するファイルが少ない |
| DB | SQLite | 無料、設定不要、1ファイルでバックアップ可能 |
| 画面 | HTML / CSS | 古いMacのブラウザでも利用しやすく、ビルド不要 |
| 配置 | Docker / Gunicorn | Render等の低コストサービスへ移行しやすい |

外部AI APIは使っていないため、APIキーも費用も不要です。秘密情報は環境変数で渡し、`.env` やDBはGitに含めません。

## まず自分のMacで動かす

Python 3.10以上をインストール後、ターミナルでこのフォルダへ移動して以下を順番に実行します。

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask --app app run
```

ブラウザで <http://127.0.0.1:5000> を開きます。停止はターミナルで `Control + C` です。次回は `source .venv/bin/activate` と `flask --app app run` だけで起動できます。

### データとバックアップ

データは初回起動時に `instance/sales.db` に作られます。アプリを止めた状態でこのファイルをコピーすればバックアップできます。サンプルを消す場合は画面で各レコードを実データに編集してください（Phase 1では誤操作防止のため削除機能は設けていません）。

## インターネット上で使う場合

このリポジトリには `Dockerfile` があります。Render、Railway、Fly.io等へ配置できますが、SQLiteを使うため**永続ディスク**を `instance/` に割り当ててください。サービスによって無料枠や仕様は変わるため、契約前に最新条件を確認してください。また公開時は次を環境変数に設定します。

```text
SECRET_KEY=十分に長いランダムな文字列
DATABASE_PATH=/永続ディスクのパス/sales.db
```

Phase 1は個人または少人数での利用を想定し、ログイン機能をまだ実装していません。インターネットへ公開するときは、サービス側のアクセス制限（Basic認証等）を必ず設定してください。

## 優先度ルール

- **S**: 宿泊施設で、ペット可・一棟貸し・複数運営・木質床のうち3条件以上
- **A**: 宿泊施設で上記条件が1つ以上、または複数施設を運営
- **B**: その他の一般的な宿泊施設
- **C**: 非宿泊施設、または判断材料が不足

判定結果は登録・編集時に更新されます。営業担当者が理由を見て最終判断してください。

## テスト

```bash
pip install -r requirements-dev.txt
pytest -q
```
